# Roadmap

## 0.1 — hardened bootstrap

- coherent Sesamo identity and Netmilk Studio sagl branding;
- ten preset sequences, same-origin destination, configurable timeout;
- cancelable browser event and deprecated prototype alias;
- normalized option reads/writes and conditional frontend loading;
- polished accessible admin UI and icon system;
- unit/smoke tests, security assessment, docs, CI, reproducible ZIP, checksum.

## 1.0 — acceptance complete

- real WordPress 6.3/current integration tests;
- Plugin Check and readme validator clean;
- desktop/mobile/zoom/RTL/assistive-tech admin QA;
- current Chrome, Firefox, and Safari runtime QA;
- WordPress.org slug decision and directory asset packaging;
- translations/POT and finalized support/reporting channels.

## Later candidates

- per-preset destinations;
- import/export with an explicit versioned schema;
- administrator-only diagnostics and Site Health integration;
- multisite policy;
- safe custom sequence builder with strict count/token/size caps;
- touch/gesture sequences and optional callbacks.

## Explicitly out of scope

- access control or authentication;
- pretending a browser-visible destination is secret;
- arbitrary external redirects;
- copyrighted game artwork;
- remote preset feeds, SaaS, telemetry, or bundled analytics.
